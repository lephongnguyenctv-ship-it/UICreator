# Code Review Reference Packs

This directory contains reference packs for the `craftland-pugc` umbrella
skill. It is not a collection of standalone skills. Do not create a nested
`SKILL.md`, a pack-specific README, or a standalone skill directory for an
individual pack.

The registry is [`packs.json`](packs.json), and the runtime contract is
[`../code_review.md`](../code_review.md). Later phases may add only packs that
have passed their review gate and have been registered in the manifest.
