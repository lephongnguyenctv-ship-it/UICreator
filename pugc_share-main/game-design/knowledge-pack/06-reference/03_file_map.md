## Operational notes
- Run the site: `cd tools/balance-web && node server.js` (port 8503). Rebuild: `node scripts/rebuild-all.js` or the Sync page.
- Sandbox with a per-call time cap: run rebuild steps one per call (list in `02-simulator/02`).
- If Git permissions block a commit, report the limitation and use the target repository's approved workflow; do not copy or overwrite `.git/` as a workaround.
- Commit or push only when authorized by the current task; the source project's delivery convention does not authorize either action here.
