Hides the full modal until tapped; tapping calls OpenShop() (for Daily Shop, checks DailyShopManager.IsReady and Boss 1 unlock first, firing PROMPT_DAILY_SHOP_LOCKED on fail).
Shop Modal Shell & Scrim (BlurBG, BG, Title, CloseButton) Container pet-shop daily-shop 1 Centered 2-column wooden stall frame over an 80%-alpha black scrim. CloseButton collapses the modal back to OpenButton (CloseShop()) and clears active selection; leaving the NPC zone hides the entire HUD.
Pet Catalog Slots (ItemsLayout / Item, 3×2 Grid) Group pet-shop 6 Cloned from ItemTemplate. Each card displays rarity-tinted frame (#AFB6BE Common → #FF5555 Mythic), dragon icon, name, and gold cost pill below. Tapping toggles the yellow Select border, opens PetDetails, and refreshes BuyButton affordability. Purchased slots display the 62%-alpha Sold Out scrim until the 5-minute rotation.
Daily Item Slots (ItemsLayout / Item) Group daily-shop 1+ Reuses ItemShopComponent via SetDataShopItem(). Displays AmountLeft (x5) in the top-left corner of the card, item icon (Void_Shard), name, price pill (500), and switches to Sold Out when stockLeft <= 0.
Refresh / Reset Countdown Bar (RefreshTimer) Status pet-shop daily-shop 1 Bottom-left steel-blue banner ticking every ~1s. In Pet Shop shows Shop will be refreshed after MM:SS (5-minute global roll); in Daily Shop shows Stock resets in HH:MM:SS until server midnight (ResetHour = 0), auto-refreshing stock across day rollover.
Pet Details Inspector (PetDetails) Panel pet-shop 1 Hidden when no slot is selected. Displays large rarity portrait, dragon name banner, rarity-colored tier pill, and 3 base Level-1 stat badges (HP, ATK, DEF) in a 2+1 layout above the BUY button.
Item Details Inspector (ItemDetails) Panel daily-shop 1 Reuses ItemDetailBackpackComponent.ShowShopItem(). Displays large rarity portrait, item name banner, multi-line description box, and AmountLeft pill (Left today: X/Y) above the BUY button.
Primary Purchase CTA (BuyButton) Action pet-shop daily-shop 1 Golden gradient (#FFB305 → #D88403) when selected item is in stock and player has enough Money; dark disabled brown (#5E4003) when unaffordable or sold out. Protected by ActionThrottleManager; Pet Shop adds dragon, marks slot Sold Out, and opens HudInfoPet; Daily Shop deducts Money, grants Void Shard, and decrements DB stock in one server tick.
GMT Debug Reset Button (ResetButton) Debug pet-shop daily-shop 1 Visible only when PlayerGMT.HasGMTPermission() is true. Resets shop rotation (Pet Shop) or clears player daily purchase count (Daily Shop) for QA testing.
